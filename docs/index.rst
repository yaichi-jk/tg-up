Welcome to tg-up's documentation!
===========================================
tg-up uses your personal Telegram account to upload and download files up to 4 GiB (2 GiB for free users).
Turn Telegram into your personal cloud!


To **install** tg-up, run this command in your terminal:

.. code-block:: console

    $ pip install -U tg-up
